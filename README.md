Savee is a curated visual-inspiration platform for designers. Its public surface is programmatic two ways: a read-only REST API — an OpenAPI 3.1 contract of 10 GET operations and 12 schemas served live from api.savee.com/v1/openapi.json, authenticated with a personal access token or OAuth 2.1 — and an official hosted MCP server at mcp.savee.com/mcp with twelve tools (eight read, four opt-in write) behind spec-conformant OAuth 2.1 with PKCE. Both require an active Savee subscription.

**Areas:** Design · visual inspiration · Image · Creative · Moodboards · Artificial Intelligence

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Savee: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
