# Savee

Curated visual-inspiration platform for designers, exposing a read-only REST API, a hosted MCP server, an llms.txt, and a published agent skill. All access requires an active Savee subscription.

- **Provider:** https://savee.com
- **Documentation:** https://docs.savee.com
- **Base URL:** https://api.savee.com
- **Tags:** design, photography, visual inspiration, creative reference, OAuth, REST, MCP, agent-native, AI-assistant integration
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 97/100

## APIs

- **Savee Public API** — Read-only REST API for accessing saves, boards, home feed, search, and user/plan data. OpenAPI 3.1 contract published live. Auth via Bearer personal access tokens or scoped OAuth 2.1 tokens. (`https://api.savee.com/v1`)

> All four surfaces (REST API, hosted MCP server at https://mcp.savee.com/mcp, llms.txt, and agent skill at github.com/saveeit/skills) confirmed against the live docs and spec. MCP server uses Streamable HTTP with OAuth 2.1 + PKCE; discovery via https://mcp.savee.com/.well-known/oauth-protected-resource. Agent skill installs via 'npx skills add' (skills.sh). OpenAPI 3.1 is the sole machine-readable contract; no AsyncAPI, GraphQL, or public Postman collection. OAuth app registration is invite-only; all access gated on an active subscription (402 if lapsed, 403 if API disabled per-account). The apis.json at https://docs.savee.com/apis.json was reported not accessible.
